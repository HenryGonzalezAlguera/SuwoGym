# Capturas de SUWÓ GYM — pendientes de incorporar

Actualmente este repositorio contiene logotipos, imágenes de ambientación y diagramas, **no capturas funcionales de las pantallas de la aplicación**.

Para completar el portafolio, captura la app funcionando con **datos ficticios**:

| Archivo recomendado | Qué capturar |
| --- | --- |
| `01-inicio.png` | Página pública con logo y navegación |
| `02-login.png` | Inicio de sesión con campos vacíos |

| `04-clases-disponibles.png` | Clases disponibles; si hay 0 horarios, no simular resultados |
| `05-admin-dashboard.png` | Administración, solo después de verificar ese rol |

Pasos:
1. Abrir [demo staging](https://suwogym-stg-web-hga-emfxdjcfccabdfh2.centralus-01.azurewebsites.net/) o ejecutar localmente con datos sintéticos.
2. Verificar que cada página realmente funcione y recortar bordes del navegador.
3. Eliminar o ocultar nombres, correos, teléfonos, contraseñas, tokens y demás datos privados.
4. Guardar PNG de buena resolución; cargar en esta carpeta usando GitHub **Add file → Upload files** o un commit local.
5. Añadir al README las imágenes **solo después de que existan**.

Para LinkedIn, usar de momento el [logotipo existente](../../SuwoGym_Web/wwwroot/images/logoSuwo_logotype.png) y el enlace de la demo. No sustituir capturas por pantallas ficticias generadas.
